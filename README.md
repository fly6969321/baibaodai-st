# 👝 百宝袋 · 酒馆版

给 SillyTavern 用的剧情投放插件，从 Tavo 版 0.5.16 移植。两个模块：

- **创意空投机** —— 开局批量建一池短纸条，之后每隔几轮抽几条塞进幕后，主回复成功才算投出去。
- **场外小叮当** —— 派人 / 顺场 / 收线 / 验收，单独一个模型跑，不写正文。

### 0.5.19 建池素材与来源校验

建池只读取角色名称、描述、性格、user 设定，以及符合角色/关键词条件的相关世界书条目。聊天首楼、角色卡开场白、角色卡场景和聊天场景覆盖都不参与建池，也不会让现有卡池失效。世界书会按角色绑定、群组成员、启用状态、关键词和条目上限筛选。

升级后，旧卡池会按相同角色基础设定和 user 设定自动迁移，保留纸条及投放记录，不调用建池 API。角色基础设定、user 设定或角色身份变化时，旧池仍会暂停，避免混用不同设定。

### 0.5.18 旧卡池与生图 / 总结插件兼容

修复旧卡池的来源兼容问题，保留已有纸条及已投记录，不调用建池 API。旧版来源迁移细节由 0.5.19 的精简来源校验处理。

### 0.5.17 空投修复

按 SillyTavern 1.19.0 的实际生成流程修复：在用户消息入库后、预设宏展开前选卡；流式回复先触发“生成结束”时，也能正确核对有效正文并结算。只有纸条实际进入本轮 system 请求，且主回复返回有效正文，才记为已投送。用户停止后保留的有效部分正文按 Tavo 版的规则结算，空回复和网络错误保留原组等待重试。

待投区只展示手动「抽取待投」的纸条，自动空投在后台完成。卡池状态显示当前可抽、待发送和已投数量；投送记录的「已投送」不表示剧情已经发生。旧版没有记录抽取来源，升级时已有的预留纸条保留在后台等待重试，可在纸条列表的待投状态中查看，不冒充手动抽取放入待投区。

隐藏或恢复旧楼不会改变助手回合计数。卡池来源只跟踪角色基础设定、user 设定和角色身份；开场变化不影响现有纸条。

## 装

酒馆 → **扩展** → **Install extension** → 填这个仓库的 git 地址 → 装完刷新页面。

右下角会出现一个 🎬 浮标，点开就是面板。浮标可以拖、可以用面板右上角的 📌 收起；收起后点 **扩展** 面板里的「👝 百宝袋」标题打开。

## 配

1. **预设里加两条条目**（对话补全预设）：角色选 **system**，打开启用，内容分别是

   ```
   {{getvar::director_chime_context}}
   ```
   ```
   {{getvar::director_coord_context}}
   ```

   变量名和 Tavo 版一样，Tavo 预设里现成的两条直接粘过来就行。放在哪个位置就从哪个位置进请求。
2. 面板 → **创意空投机** 页 → 展开 **空投 API**：填中转站地址、密钥，点「拉取模型列表」选模型，保存。
   **场外小叮当** 页同理，默认勾着「完全复用创意空投机的中转和模型」，想换个便宜模型就取消勾选单独配。
3. 回 **创意空投机** 页 → **卡池状态** → 勾「同意…付费建池」→「开始建池」。

面板最下面 **诊断** 会写当前预设两条条目在不在。缺哪条就点名哪条，缺着的模块不抽卡、不花钱。

## 和 Tavo 版不一样的地方

| | Tavo 版 | 酒馆版 |
|---|---|---|
| 请求中转站 | 直连 | 先试直连，被浏览器跨域拦了自动改走酒馆后端转发 |
| 配置存哪 | Tavo 全局变量 | 酒馆的 `extension_settings` |
| 每个聊天的卡池和两个变量 | Tavo 聊天变量 | 聊天自己的 `chat_metadata`，跟着聊天文件走 |
| 条目位置 | 只认相对位置 | 相对位置、聊天内深度都认 |

卡池、分类筛选、盲抽 / 参考互动选卡和多中转档案沿用 Tavo 版。酒馆版针对自身生成事件实现预留与成功扣卡，并将手动待投展示、自动投送记录和剧情兑现分开。

## 注意

- 预设编辑器里点 token 预览会触发一次空转的生成流程，插件已经跳过它，不会白花钱。
- 重新生成和 swipe 不会重新抽卡，也不会把「隔几轮投一次」的计数清零；手动改正文或删楼会撤下当前纸条（旧建议不再可靠），但同样不动计数。
- 主回复没出来，或发生网络错误时，这一组纸条会留着给重试用，不会扣掉。
- 没有纸条时变量是空的，那条条目整条不发，不会多出一条空消息。
