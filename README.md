# 👝 百宝袋 · 酒馆版

给 SillyTavern 用的剧情投放插件，从 Tavo 版 0.5.16 移植。两个模块：

- **创意空投机** —— 开局批量建一池短纸条，之后每隔几轮抽几条塞进幕后，主回复成功才算投出去。
- **场外小叮当** —— 派人 / 顺场 / 收线 / 验收，单独一个模型跑，不写正文。

## 装

酒馆 → **扩展** → **Install extension** → 填这个仓库的 git 地址 → 装完刷新页面。

右下角会出现一个 🎬 浮标，点开就是面板。浮标可以拖、可以用面板右上角的 📌 收起；收起后从 **扩展** 面板里的「👝 百宝袋 → 打开面板」进。

## 配

1. **预设里加两条条目**（对话补全预设）：角色选 **system**，打开启用，内容分别是

   ```
   {{getvar::director_chime_context}}
   ```
   ```
   {{getvar::director_coord_context}}
   ```

   变量名和 Tavo 版一样，Tavo 预设里现成的两条直接粘过来就行。放在哪个位置就从哪个位置进请求。
2. 面板 → **创意空投机** 页 → 展开 **空投 API**：填中转站地址、密钥，点「拉取模型列表」选模型，保存。
   **场外小叮当** 页同理，默认勾着「完全复用创意空投机的中转和模型」，想换个便宜模型就取消勾选单独配。
3. 回 **创意空投机** 页 → **卡池状态** → 勾「同意…付费建池」→「开始建池」。

面板最下面 **诊断** 会写当前预设两条条目在不在。缺哪条就点名哪条，缺着的模块不抽卡、不花钱。

## 和 Tavo 版不一样的地方

| | Tavo 版 | 酒馆版 |
|---|---|---|
| 请求中转站 | 直连 | 先试直连，被浏览器跨域拦了自动改走酒馆后端转发 |
| 配置存哪 | Tavo 全局变量 | 酒馆的 `extension_settings` |
| 每个聊天的卡池和两个变量 | Tavo 聊天变量 | 聊天自己的 `chat_metadata`，跟着聊天文件走 |
| 条目位置 | 只认相对位置 | 相对位置、聊天内深度都认 |

卡池、纸条预留与扣卡、分类筛选、盲抽 / 参考互动选卡、生命周期降权、多中转档案、提示词与界面文案，都和 Tavo 版一致。

## 注意

- 预设编辑器里点 token 预览会触发一次空转的生成流程，插件已经跳过它，不会白花钱。
- 重新生成和 swipe 不会重新抽卡，也不会把「隔几轮投一次」的计数清零；手动改正文或删楼会撤下当前纸条（旧建议不再可靠），但同样不动计数。
- 主回复没出来（报错、被你按停）时，这一组纸条会留着给重试用，不会扣掉。
- 没有纸条时变量是空的，那条条目整条不发，不会多出一条空消息。
